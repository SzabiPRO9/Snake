Snake - Bomb Run

In this game the user can direct a snake, which has to catch apple to grow itself. If it accidentally eat a bomb, its size will decrease.
The game will over,
  if the snake size is one and eat a bomb. (the bomb is changing its position during the party)
  if the snake hit the edge of the field.
You could save your highest score.
